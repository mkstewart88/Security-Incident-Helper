# Code of Conduct & Repository Scope

## Static Code Release Notice
This repository is published strictly as a static, unmaintained code release on an **"as-is"** basis. The author does not actively manage, moderate, or maintain community discussions, issues, or pull requests, and assumes no duty of active stewardship or support.

## Baseline Standards of Conduct
Anyone viewing, interacting with, or discussing this project or its public forks is expected to maintain standard professional conduct:
* Treat other professionals and contributors with respect.
* Do not publish sensitive credentials, private organization domain names, internal IP addresses, or personally identifiable information (PII) in public comments or issues.
* Do not demand technical support, feature additions, or bug fixes. This repository is provided without support, warranty, or maintenance obligations.

## Maintainer Discretion
Because this repository is provided as-is, the author has no obligation to review or respond to issues, discussions, or pull requests.
